# Space Strategy — прототип логистики

Unity 6000.3.25f1 / Universal 2D. Первый срез GDD: три мира, два маршрута, производство и один флот.

## Запуск

Откройте проект в Unity Hub. В Unity выберите **Space Strategy → Create prototype scene**, затем нажмите Play.
После первого создания сцена находится в `Assets/SpaceStrategy/Scenes/LogisticsPrototype.unity`.
Для сборки Windows выберите **Space Strategy → Build Windows prototype**. Сборка появляется в `Builds/SpaceStrategyPrototype`.

## Что попробовать

Стенд v0.2: в панели флота выберите Эридан IV, Землю или Бастион, затем способ перемещения. Нажатие на планету карты тоже выбирает цель, но не отправляет флот без команды. Земля ↔ Эридан теперь доступен; переход Бастион ↔ Эридан проходит через Землю. Флот и его снабжение используют соответствующий участок сети. В гиперпрыжке расходуется только бортовой запас.

Актуальная согласованная модель ресурсов и логистики: [ProductionResourcesLogistics_v0.3.md](Docs/Mechanics/ProductionResourcesLogistics_v0.3.md). Зафиксированы 8 ресурсов: глобальные потоковые — металлы, редкоземельные металлы, химические элементы, сверхпроводники, минералы и гиперматериал; локальные складируемые — топливо и боеприпасы. Глобальные ресурсы не копятся и подключаются к общему имперскому пулу через столичную экономическую сеть. Топливо и боеприпасы реально хранятся на планетах; глобальные проценты показывают агрегированную заполненность имперских складов. Земля остаётся главным распределительным хабом, но не буквальным складом всей империи. ТНП — не ресурс, а доля ПЧ, занятая гражданской экономикой; её процент меняется решениями, баффами и дебаффами. Предыдущая спецификация [ProductionLogistics_v0.2.md](Docs/Mechanics/ProductionLogistics_v0.2.md) остаётся историей решений по производственным линиям и эффективности. Эта модель реализована в отдельном экономическом стенде v0.3, описанном ниже; старый прототип сохраняет прежнюю упрощённую модель.

1. Выберите маршрут Земля → Бастион и нажмите «Мощность 20».
2. Переключитесь на скорость 8×. Сначала расходуется резерв флота; после его истощения падает снабжение и организация. Бастион также расходует сырьевой запас, затем снижает выпуск.
3. Нажмите «Восстановить»: снабжение возвращается, запасы пополняются, организация восстанавливается.
4. Выберите Эридан IV и остановите добычу. Земля и Бастион некоторое время работают на запасах, затем теряют выпуск. Возобновите добычу для восстановления.
5. Перебросьте флот на Землю. Обычный путь занимает от шести часов, расходует 10 топлива и добавляет 25 единиц нагрузки на маршрут. Гиперпрыжок занимает два часа, расходует 30 топлива и 35 организации.
6. У Земли закажите фрегат за 2000 ПЧ. Свободный выпуск после снабжения идёт в строительство. Новый корабль увеличивает расход снабжения на 6 единиц в час. Флот остаётся на верфи до завершения заказа.

Пробел — пауза; кнопки 1×, 4×, 8× — скорость. При 1× игровой час занимает четыре реальные секунды.

## История изменений (Git)

Проект использует локальный Git, основная ветка — `main`. Откройте папку проекта в VS Code и нажмите Ctrl+Shift+G: панель «Управление версиями» показывает изменения и позволяет делать коммиты.

В историю входят `Assets` вместе с файлами `.meta`, `Packages`, `ProjectSettings` и документация. Кэш Unity (`Library`, `Temp`), логи, сборки и локальные настройки не отслеживаются. Unity уже использует текстовую сериализацию сцен и ассетов. Изображения, модели и аудио настроены на Git LFS; при переносе проекта на другой компьютер нужно установить Git LFS и выполнить `git lfs install`.

Удалённый репозиторий `origin`: https://github.com/Streels/SpaceStrategy. Основная ветка — `main`; первый прототип опубликован. Новые локальные изменения публикуются отдельным коммитом и `git push` после проверки.

## Устройство модели

- `Assets/SpaceStrategy/Domain/StrategySimulation.cs`: чистая C#-модель экономики, запасов, маршрутов, перемещения и строительства; независима от Unity.
- `Assets/SpaceStrategy/Presentation/PrototypeController.cs`: интерактивная 2D-карта и диагностический интерфейс.
- `Assets/SpaceStrategy/Editor/PrototypeBuilder.cs`: создание сцены, проверки и сборка.
- `Assets/SpaceStrategy/Editor/SimulationChecks.cs`: проверки дефицита, резервов, восстановления, перемещения, строительства и независимости от частоты кадров.

Ресурсы распределяются пропорционально спросу. Обе промышленные планеты получают сырьё от Эридана IV; снабжение производится на Земле. Каждый маршрут совместно обслуживает гражданский поток, ресурсы и удалённое снабжение. Резервы восполняются небольшим излишком поставок. Выпуск равен мощности × зрелости × темпу × обеспеченности сырьём.

## Границы среза

Корабли представлены числом фрегатов в одном соединении; бои, конструктор, колонизация, развитие населения и сохранения пока отсутствуют. Промышленный приоритет Земли сразу изменяет её доступную мощность — временное упрощение для проверки зависимости производства от сети. Графика и интерфейс процедурные, без внешних ассетов. Прототип начинается заново при каждом запуске.

## Отдельный экономический стенд v0.3

В Unity выберите **Space Strategy → Create economy stand v0.3**, затем Play. Это новая отдельная сцена `Assets/SpaceStrategy/Scenes/EconomyStand.unity`; старая `LogisticsPrototype` сохраняется.

Слева — общая очередь с ручными назначениями ПЧ и независимой эффективностью линий. Справа — вкладки ресурсов, физических складов, сети и экспериментальных настроек. Уточнения и ограничения: [EconomyStand_v0.3.md](Docs/Mechanics/EconomyStand_v0.3.md).

Уточнённые ресурсные штрафы применяются последовательно: дефициты 20% и 50% дают `100 → 80 → 40`, а не 30 или 50. Потребность ресурсов растёт с назначенными ПЧ; транспорт на старте распределяется сбалансированно, пропорционально спросу.

Проверки: **Space Strategy → Run economy checks v0.3**. Сборка: **Space Strategy → Build Windows economy stand v0.3**; при успешной сборке результат — `Builds/SpaceStrategyEconomy_v0.3/SpaceStrategy.exe`. Исходники, сцена и проверки входят в Git; сборки и кэш Unity не публикуются.

Статус на 2026-10-02: 93 проверки экономики и 38 прежних проверок проходят. После перезапуска Unity новая сцена проверена в Play Mode; штатная Windows-сборка успешно создана в `Builds/SpaceStrategyEconomy_v0.3/SpaceStrategy.exe` и запущена отдельно. Проверены назначение ПЧ, изменение эффективности, вкладки ресурсов / складов / сети, перемещение Земля → Эридан и блокада с восстановлением снабжения. Флот пополняется из местного резерва только на орбите; в пути использует бортовые запасы. Техническая проверка текущего стенда завершена в объёме, указанном в документации. Прежний диагностический пакет на базе старого плеера не используется.

Разгон эффективности теперь замедляется тем же итоговым ресурсным коэффициентом, что и выпуск. При полном дефиците разгон останавливается, накопленное освоение сохраняется; при восстановлении ресурсов рост продолжается.

По решению пользователя окончательный игровой баланс настраиваем в самом конце разработки. До этого сосредотачиваемся на механиках и корректности расчётов; текущие численные параметры остаются тестовыми.
